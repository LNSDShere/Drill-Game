⛏️ MOTHERLODE
💥 Drill deep. Strike it rich. Try not to blow up.
The Gold Rush Mining Co. · Deep-Earth Division is hiring. You get a drill pod, $120, and a dream. Somewhere 1,080 meters straight down sits THE VAULT — and everything between you and it is rock, ore, lava, gas, and questionable decision-making. DIG · BLAST · HAUL · NEGOTIATE.

One HTML file. No installs, no build step, no engine, no accounts. A love letter to the Flash-era mining classics — with a market that moves, mineshafts that collapse, and a news ticker you should absolutely not trust.

🚀 How to Play (30 seconds)
Hit the green Code button → Download ZIP (or git clone).
Unzip. Double-click index.html.
That's it. You're a miner now. 🪙
The game auto-saves to your browser as you play. Want a fresh start? Hit ERASE SAVE on the title screen. Works in any modern desktop browser — and if you delete the image files, the game falls back to its built-in vector art, so it truly runs anywhere.

⌨️ Controls
Key	Action
A / D or ← →	Sideways thrust — or drill sideways while grounded
W / ↑ / Space	Main thruster — going up burns fuel, falling is free (and painful)
S / ↓	Drill the tile below you
E	Dock at a surface station
Q	Sonar ping — gems glow, gas flashes red, geodes show gold
X	Plant dynamite — 5×5 blast through ANY rock. Then run. 🏃
B	Field coal burner — 4 coal → 30L of fuel (small chance of backfire)
T	Emergency teleporter — instant surface, cargo intact
ESC	Pause

☠️ Hazards (the fine print)
🌋 Lava — pours into any hole you dig beneath it. Never dig straight down under lava.
💨 Gas pockets — look like cracked rock, detonate in a 3×3 blast.
🪨 Geodes — grey boulders with a glowing seam. Crack one open for a gem shower.
🪵 Old shafts — free loot in the crates, but the timber holds the ceiling up. Cut a support and it all comes down.
🧱 Loose rock — that cracked ceiling tile above you? Mine sideways first.
🫨 Tremors — below 700 m, whole rooms shake loose. Nowhere is safe.
⛽ Run dry and you get towed — a fee for every metre. Break the hull and the rescue crew keeps your cargo as a souvenir.
🏆 The Vault
The run ends 1,080 m down, right through the basalt, at the Motherlode itself. Crack it open for a $25,000 bonus and unlock Endless Mode with a permanent boom market — +25% on every price, forever. The digging continues. 💸
